# mustang

WordStar 3.3 っぽい TUI のテキストエディタ。Rust + [crossterm](https://github.com/crossterm-rs/crossterm) 製で、Windows Terminal をはじめ主要なターミナルで動きます。

## 特徴

- WordStar 3.3 のダイヤモンドキー（`^E`/`^X`/`^S`/`^D` など）と `^K` / `^Q` の 2 段プレフィックスコマンドを再現
- ブロック選択・コピー・移動・削除・ファイル書き出し（`^K B/K/C/V/Y/W/R`)
- 検索・置換（`^Q F` / `^Q A`、Y/N/A/Esc で確認しながら置換）
- 挿入/上書きモード切り替え（`^V`）
- タブ・全角文字（日本語などの East Asian Wide 文字）を考慮した表示幅計算
- CRLF / LF を検出して保存時に維持
- 画面下部に WordStar 風のキーガイド（`^O H` で表示/非表示切り替え）、`^J` / `F1` でヘルプ画面

## ビルド

```sh
cargo build --release
```

生成されたバイナリは `target/release/mustang`（Windows では `mustang.exe`）です。単一の実行ファイルなので、Windows Terminal の PATH の通った場所に置くだけで使えます。

## 使い方

```sh
mustang [ファイル名]
```

ファイル名を省略すると無題のバッファで起動します。指定したファイルが存在しない場合は、そのファイル名を保存先として新規バッファを開きます。

Windows Terminal で使う場合は、PowerShell / コマンドプロンプト / WSL のどのプロファイルからでもそのまま起動できます（クロスプラットフォームな `crossterm` バックエンドを使用しているため）。

## キーバインド一覧

### カーソル移動（ダイヤモンド）

| キー | 動作 |
| --- | --- |
| `^E` / `↑` | 1 行上 |
| `^X` / `↓` | 1 行下 |
| `^S` / `←` | 1 文字左 |
| `^D` / `→` | 1 文字右 |
| `^A` | 1 単語左 |
| `^F` | 1 単語右 |
| `^Q S` / `Home` | 行頭へ |
| `^Q D` / `End` | 行末へ |
| `^Q E` | 画面の先頭行へ |
| `^Q X` | 画面の最終行へ |
| `^Q R` | 文書の先頭へ |
| `^Q C` | 文書の末尾へ |
| `^R` / `PageUp` | 1 画面上へスクロール |
| `^C` / `PageDown` | 1 画面下へスクロール |
| `^Q L` | 指定行へジャンプ（mustang 拡張） |

### 編集

| キー | 動作 |
| --- | --- |
| `^G` / `Delete` | カーソル位置の文字を削除 |
| `^H` / `Backspace` | カーソル左の文字を削除 |
| `^T` | カーソルから単語末尾までを削除 |
| `^Y` | カーソル行を丸ごと削除 |
| `^Q Y` | カーソルから行末までを削除 |
| `^N` | 行を分割して新しい行を開く（カーソル位置は変えない） |
| `Enter` | 改行 |
| `Tab` | タブ文字を挿入 |
| `^V` | 挿入モード / 上書きモードの切り替え |

### ブロック操作

| キー | 動作 |
| --- | --- |
| `^K B` | ブロック開始位置をマーク |
| `^K K` | ブロック終了位置をマーク |
| `^K C` | ブロックをカーソル位置にコピー |
| `^K V` | ブロックをカーソル位置に移動 |
| `^K Y` | ブロックを削除 |
| `^K H` | ブロックの表示（反転表示）を切り替え |
| `^K W` | ブロックを別ファイルに書き出す |
| `^K R` | ファイルの内容をカーソル位置に読み込む |
| `^Q B` | ブロック開始位置へジャンプ |
| `^Q K` | ブロック終了位置へジャンプ |

### 検索・置換

| キー | 動作 |
| --- | --- |
| `^Q F` | 文字列を検索（文末まで検索したら先頭に折り返す） |
| `^Q A` | 検索して置換（1 件ずつ `Y`=置換 / `N`=次へ / `A`=残り全部置換 / `Esc`=中止） |
| `^L` | 直前の検索を繰り返す |

置換はカーソル位置から文書末尾に向かって検索します（「全置換」を実行しても、既に確認・スキップ済みの箇所へ巻き戻ることはありません）。文書全体を対象にしたいときは `^Q R` で先頭に移動してから `^Q A` してください。

### ファイル

| キー | 動作 |
| --- | --- |
| `^K S` / `^K D` | 保存（編集を継続） |
| `^K X` | 保存して終了 |
| `^K Q` | 保存せずに終了（未保存の変更があれば確認あり） |

### その他

| キー | 動作 |
| --- | --- |
| `^O H` | 画面下部のキーガイドの表示/非表示 |
| `^J` / `F1` | ヘルプ画面（任意のキーで閉じる） |
| `Esc` | `^K` / `^Q` プレフィックスやプロンプトのキャンセル |

## 制限事項

- ファイルは UTF-8 テキストのみ対応です。
- ワードラップ・段落整形（WordStar の `^B` / `^O` 書式コマンド）は未実装です。
- Undo は未実装です（オリジナルの WordStar 3.3 自体に Undo 機能がありませんでした）。

## テスト

```sh
cargo test
```

バッファ操作（範囲抽出・削除・多行挿入・検索の折り返し）とエディタの主要コマンド（挿入・削除・単語移動・ブロック操作・検索置換・保存/終了フロー）を単体テストでカバーしています。
